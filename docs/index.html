BalapinPCBridge - Privacy Policy

Privacy Policy

Last updated: November 2026

This privacy policy describes how the BalapinPCBridge software ("we", "our", "us") collects, uses, and discloses information when you use the BalapinPCBridge application running on Windows.

1. Information We Collect

1.1 UDP Network Data

When you run BalapinBridge and connect your Android device to the same WiFi network, the application receives UDP packets from the Balapin PC Bridge Android app. This data includes:

  • Steering values (-1.0 to 1.0)
  • Throttle values (0.0 to 1.0)
  • Brake values (0.0 to 1.0)
  • Button ABXY bitmask
  • Race control flags (DRS,ERS,ABS,TC,PIT_LIMIT,PIT_IN)
  • Sequence numbers and timestamps

This data is received in real-time via UDP protocol and is not stored permanently unless you choose to enable logging via the --status flag, which saves a log file to C:\ProgramData\Balapin\bridge.log.

1.2 Technical Information

We automatically collect certain technical information about your system, including:

  • Windows operating system version
  • Processor architecture (x64/arm64)
  • ViGEmBus driver status (installed/Not installed)
  • Task Scheduler status (running/stopped/not installed)
  • Local IP address (used for firewall rule creation)

2. How We Use Your Information

The information we collect is used solely for the following purposes:

  • Primary Function: To receive UDP data from your Android device and convert it into virtual Xbox 360 gamepad input, allowing you to use your Android as a controller for racing games like F1 2020.
  • Driver Management: To detect and install the ViGEmBus driver required for virtual gamepad functionality.
  • Auto-start Configuration: To create a Windows Scheduled Task (ONLOGON) so the bridge runs automatically when you log into Windows.
  • Debugging: To troubleshoot connection issues via the optional log file.

3. Data Storage and Retention

We do not permanently store your UDP network data. The only persistent data we may create is:

  • Log file: If you run BalapinBridge.exe --status, a log file is created at C:\ProgramData\Balapin\bridge.log. This contains recent UDP packets for debugging purposes. You can delete this file at any time.
  • Windows Task: The auto-start task is created in Task Scheduler under the name "BalapinBridge". This only runs the executable; it does not collect or transmit data.

We do not sell, rent, or share your personal information with third parties for marketing or advertising purposes.

4. Third-Party Services

BalapinPCBridge uses the following third-party components:

ViGEmBus 1.22.0

The Virtual Xbox 360 gamepad functionality is provided by ViGEmBus, an open-source driver that emulates Xbox 360 controllers. ViGEmBus is distributed under the GNU General Public License v3.0 (GPLv3). By using BalapinPCBridge, you agree to the terms of the GPLv3 license for the ViGEmBus component. For more information, visit https://github.com/nefarius/ViGEmBus

vgamepad Library

The Python library used for ViGEmBus interaction is vgamepad (version 0.1.0), which is also open-source software. See the repository for licensing details.

5. Security

We implement appropriate security measures to protect your information. However, remember that UDP is a connectionless protocol and data packets can be intercepted on unsecured networks. We strongly recommend using BalapinPCBridge only on trusted, private WiFi networks.

6. Your Rights

You have the right to:

  • Disable the auto-start feature at any time via BalapinBridge.exe --uninstall-autostart
  • Delete the log file at C:\ProgramData\Balapin\bridge.log
  • Uninstall the ViGEmBus driver if no longer needed
  • Contact us with any questions about your data

7. Changes to This Privacy Policy

We may update our privacy policy from time to time. We will notify you of any changes by posting the new privacy policy on this page. You are advised to review this privacy policy periodically for any changes.
