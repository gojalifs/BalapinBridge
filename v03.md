\## 🏁 V0.3: PC Bridge + Game Input



Tujuan: Menghubungkan Android Controller ke PC Windows 11, lalu mengubah data steering menjadi input yang bisa dibaca game F1 2020.



\### Fitur yang dikerjakan



1\. PC Bridge (Kotlin/Python/C#)



\* Menerima data steering dari Android melalui UDP.



\* Menampilkan nilai steering secara real-time.



\* Memantau koneksi Android.



2\. Konversi Steering → Game Input



\* Mengubah nilai steering `-1 hingga +1` menjadi input kiri dan kanan.



\* Mengatur sensitivitas dan deadzone.



\* Mencegah input bergetar ketika HP diam.



3\. Integrasi ke F1 2020



\* Menghubungkan input virtual ke game.



\* Menguji apakah setir Android bisa mengendalikan mobil.



\* Menguji responsivitas dan kestabilan steering.



\### Hasil akhir V0.3



Android → UDP → PC → F1 2020



HP Android berfungsi sebagai setir, dan gerakan gyro diterjemahkan menjadi kontrol kemudi di PC.



Steering aktif



UDP aktif



Tanpa FFB



V0.3 belum mencakup: Force Feedback, pedal fisik, atau casing steering wheel.



Intinya, V0.1 = baca gyro. V0.2 = kirim data lewat Wi-Fi. V0.3 = pakai data itu buat nyetir mobil di game. 🏎️
